# 工厂菜单精简

执行 `014_simplify_navigation.sql` 后，隐藏零售管理、零售统计、会员信息、组装单、拆卸单和原销售出库。历史单据、原有角色授权及底层库存接口保留。重新登录或刷新页面加载新菜单。

发货统一进入「销售管理 → 发货申请与装车出库」。

菜单显示规则：

- 平台管理员和租户负责人可查看租户、菜单、插件、字典、平台配置、多单位、多属性维护入口；其他账号收起这些入口。
- 其它入库、其它出库仅向上述管理员或拥有「订单库存核查」菜单权限的仓库岗位展示，且仍须具备原入口授权。
- 采购、财务及报表入口保留；财务是否交由外部系统处理尚未最终确定。
- 用户、角色、日志、商品、客户、供应商、仓库及工厂业务主线保留。

这是导航精简，不新增业务授权，也不代替接口自身的权限和单据校验。现有角色若拥有仓库权限，仍按仓库岗位显示；实际岗位应在角色管理中据实分配。

需要恢复隐藏入口时，可由管理员在菜单管理重新启用对应 URL。变更前数据库备份：本机忽略目录 `.quality-local/before-navigation.sql`。
