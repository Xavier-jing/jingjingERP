# 成品质检、整批入库与领导放行

入口：「生产管理 → 成品质检入库与放行」。新菜单未出现时退出并重新登录。

## 人员和检测标准

- 质检人员、质检主任沿用原质检模块。在「商品管理 → 产品质检标准」选择产品及“成品”，维护最终检测标准，或引用共用模板；成品标准独立于半成品工序标准。详见 `quality-standard-guide.md`。
- 租户负责人点击「放行领导配置」，可选择多位有效账号。任意一位批准即完成整批放行，不要求逐人会签。
- 仓库入库使用现有「订单库存核查」岗位权限，并校验账号对所选仓库的访问权限。质检、领导及仓库账号需要在角色管理中配置对应菜单，以便进入页面。

## 最终抽样送检

半成品检测用于中间工序交接，最后一道工序产出进入成品最终抽样检测，不按每天的日报重复送检。

1. 对应产出车间主任打开任务，核对产品、批号及最后一道工序的累计产出。相同产品同批号在最后一道工序跨日、多个车间的产出合并为一批。
2. 全批生产完成后点击「整批最终送检」。整批数量由系统汇总，不能手填部分数量。只送样品，实物仍在车间。
3. 发起送检后固定该批数量，不能再追加该批最后一道工序的生产日报。尚未生产完不要提前最终送检。
4. 质检人员填写、保存最终检测分表后提交。超区间数值标红，标准和实际检测数据随送检记录留存。
5. 质检主任判定整批合格或整批不合格，不拆分合格数量；有超标指标、不合格时必须说明判定及处理意见。
6. 整批不合格由原主任填写调整说明、申请整批复检。复检沿用原批号和固定数量，重新填写检测分表。保留原单结果及关联，不覆盖原始检测值。

## 整批入库

质检主任确认整批合格后，仓管选择仓库，核对实物，确认整批入库。系统按固定数量生成原库存系统的「其它入库」单，编号为 `CPRK` 加成品批次记录号；不再要求重复手工开入库单。

同批不允许重复或分次入库。商品必须启用批次管理，基本单位为吨；已有相同商品、批号的其他库存收发记录时会要求先核实，避免混入另一批库存。每个成品批次关联一张生产任务，同商品批号不能重复归属其他任务。

入库后即形成实物库存，仓管可按原流程给销售订单预留；最终检测汇总报告在库存批次上可查看。入库不等于放行，待放行库存不能出库。

本次联动数量库存，未接入生产成本核算，生成入库单金额按零记录；不得把该金额当作真实生产成本或销售毛利依据。

## 多位领导整批放行

1. 任意一位已配置领导查看最终检测分表、主任结论及入库记录后，批准整批放行。
2. 系统记录实际处理领导、时间和说明。多人同时批准只会成功一次，不能重复放行或拆分数量。
3. 不予放行必须填写处理意见，该批维持禁止出库。原车间主任记录执行结果后重新申请，再由任意配置领导审核。
4. 本次「记录处理结果」不移动库存、不修改检测数据。若意见涉及已入库实物退回车间返工，必须先明确仓库退回及复检流程，不能把填写说明当成实物已经出库或完成复检。

原系统出库接口同样受整批放行限制；成品入库单不能绕过模块直接修改、删除或反审核。放行后的出库仍受订单库存预留保护。受管批次的累计出库不能超过固定的整批数量；跨仓转库及客户退货需后续明确相应单据的批次核算，不应借普通其它出入库自行重建该批。

本次完成质检、库存和领导放行；整单备齐发货、销售车辆登记、装车照片及收款条件核验在后续发货模块衔接。领导的本次操作表示产品放行，不代替财务到账确认。
