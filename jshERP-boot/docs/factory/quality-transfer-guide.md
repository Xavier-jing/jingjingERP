# 半成品送检与车间流转

入口：重新登录后进入「生产管理 → 半成品送检与流转」。

## 首次配置

1. 租户负责人点击「质检人员配置」，选择正式质检主任及分表填写人员。主任需要填写分表时，也应加入填写人员。质检账号在角色管理中需具有生产管理下的本模块菜单权限。
2. 质检主任或租户负责人打开「商品管理 → 产品质检标准」，选择具体产品（含牌号、规格对应的商品编码）、半成品及工序序号。
3. 选择共用模板或维护独立分表，支持数值范围和文字判定。上下限均包含边界，允许单侧限制；未设标准表示人工判定，不自动判为合格。详见 `quality-standard-guide.md`。
4. 保存后生成标准版本。正式指标和区间以工厂真实检测表为准，系统不预置正式标准。

## 送检与检测

### 开始检测与多人协作

质检人员配置可同时选择多名分表填写人员。查看送检单不会锁定；任一配置质检员点击「开始检测」后，状态从「待开始检测」变为「检测中」，立即禁止车间修改或删除，即使尚未填写检测值。未开始检测不能保存分表或提交主任。开始人及时间保留在操作记录中；历史已保存检测分表的单据按检测中继续处理。

配置的质检员可按分表分工，分表记录最后录入人、时间及修改履历。系统以单据版本防止旧页面覆盖其他人的保存，遇到更新提示须重新打开。各表保存齐全后由一位质检员统一提交质检主任，主任可退回补充检测。开始检测不独占整单；其他配置质检员仍可参与填表。

未开始检测的半成品申请，原送检车间主任可在送检记录点击「修改送检」或「删除」。修改可调整代表数量及说明，保存时采用本产品工序最新标准；任务、工序、车间和批号保持不变。删除后释放对应可送检数量，操作履历仍保留。已有检测填写、提交、确认、交接或复检记录的单据不能修改删除；不直接改写历史检测结果。成品最终整批送检不使用此入口。

1. 进入生产任务的「送检 / 检测 / 交接」，本车间主任从日报批次产出申请送检。
2. 填写的是样品代表的生产数量（吨），不是样品重量。只送样品，实物留在车间。未配置该产品工序的标准时不能申请。
3. 多日同批次产出合并计算，累计初检代表数量不能超过日报累计产出。已送检数量不能重复初检。
4. 质检人员打开送检单，分别填写、保存各检测分表。多人协作时，若单据版本冲突，应重新打开核对后继续；不要直接覆盖其他人的检测数据。
5. 所有分表填写后提交主任。超区间数值标红，原始数值保留。无区间的指标显示人工判定。
6. 主任可退回补充检测数据，或确认合格数量及处理说明。不合格数量＝代表数量－合格数量。任一有明确标准的数值或文字指标不合格，本次送检合格数量必须为0，并填写处理说明；不能仅写说明后按全部或部分合格放行。正常指标也须明确填写判定数量，不默认全量合格。

标准在申请送检时保存到单据中，之后调整标准不会重算旧单据。已提交的检测数据不可直接修改；主任退回后可更正并重新提交。主任已确认的记录不提供修改、删除入口，原始数据、更正及确认过程均保留。

## 不合格调整与复检

原车间主任在已确认送检单上点击「调整后复检」，填写调整说明及复检数量。复检累计数量不能超过原单不合格数量。新复检单使用申请当时的检测标准，保留与原单的关联；原单结果不会被覆盖。复检后仍不合格可继续关联复检，不在此模块直接决定报废。

## 合格交接与继续生产

1. 原车间主任从已确认送检单点击「交接」，按统筹现有安排选择下一工序及接收车间。相邻工序在同一车间时，也登记工序交接。
2. 可分次、分车间交接，累计交接不超过本单合格数量；下一车间累计待接收及已接收数量不超过其分配量。无下一工序时，不提供交接到任意车间的入口。
3. 接收主任核对实物后点击「确认收到」，系统记录交接双方账号、时间和数量。当前按单上数量整笔确认；数量有差异时先核实，不确认错误数量。
4. 跨工序沿用原批号。第二及以后工序必须有已确认接收记录才能开工；日报按该批号录入，累计投入不能超过对应批号已接收数量。
5. 车间交接不会增加成品仓库库存。最终成品质检、高层放行、成品入库仍在后续模块衔接。

销售、统筹及有本模块查看权限的人员可查进度；质检页面不显示销售价格、金额。系统按租户隔离数据。

## 更正已确认判定

质检主任可在已确认送检单点击「更正判定」，必须填写原因；已存在交接、复检或成品入库时阻止直接更正。系统保留原合格数量、原确认人和时间、原意见及本次更正履历，不改动原始检测值。更正为不合格后，原车间主任从原单申请调整后复检。
