# 实际开工与生产日报

重新登录后进入「生产管理 → 开工与生产日报」，选择已排班任务，点击「开工 / 日报 / 进度」操作。生产任务联系表详情仅保留进度及日报查看。

1. 生产统筹先分配产品、工序、车间，各主任分别接单并完成排班。
2. 对应主任在本车间产品工序点击「确认开工」，填写实际时间并核对原料齐套。
3. 开工后点击「录生产日报」，填写日期、批号、投入、产出、损耗和备注，数量单位为吨。
4. 有联系表查看权限的销售、统筹及领导可在详情查看实际开工、各工序累计产出与日报。

同日、同产品工序、同车间、同批号只录一条；日报日期在开工日至今天之间；产出与损耗合计不得超过投入，累计产出不得超过分配量。各工序分别统计，不能相加当作成品量。

开工后不能直接覆盖该车间排班。日报可由对应车间主任直接更正，无需审批，不能直接删除。原料齐套由主任人工核对，不依据领料数量自动推断。日报不会自动扣原料或增加成品库存。

## 日报直接更正

在「生产管理 → 开工与生产日报」打开任务，找到日报行，点击「更正日报」。对应车间的当前配置主任可更正日报日期、批号、投入、产出、损耗和备注；产品、工序、车间及原录入人不变。更正原因必填，保存立即生效，无需审批。

「更正记录」按日报展示每一次更正前后的完整内容、原因、操作人和时间。最初录入人及录入时间保留，累计产出使用更正后的数值。只读进度页也可以查看更正记录。

- 更正后继续校验日期、数量精度、投入与产出损耗关系、同日同批号唯一性及工序计划上限；累计数扣除该日报原数量后重新计算。
- 第二及以后工序可以在自己的产出尚未送检前更正，但同批号累计投入不能超过上工序实际确认接收量。
- 日报按车间、产品、工序、批号与送检关联。只要该组产出已经送检，即使尚未检完或只送检了部分数量，相关日报也不能直接更正；已经交接的源工序日报同样禁止。不能通过修改日期、改批号或只改备注绕过限制，也不能把其它日报改入已送检批号。
- 最终送检固定整批数量，相同产品工序批号的所有相关车间、所有日期日报都禁止直接更正，成品入库后也一样。
- 同时更正只允许一个版本保存；更正与送检在同一事务锁内读取最新产量，失败不会留下修改了一半的日报或更正记录。

沿用现有生产操作记录表保存前后快照，无需新增数据库表或迁移。集成检查：`tests/factory_report_correction_workflow.py`；使用临时任务检验直接更正、权限、数量、快照、并发、送检交接锁定和租户隔离，结束后恢复配置并清理。
