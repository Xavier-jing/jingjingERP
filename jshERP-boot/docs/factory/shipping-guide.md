# 发货申请与装车出库

入口：「销售管理 → 发货申请与装车出库」。也可以从销售订单的「发货申请 / 进度」进入。新增菜单未显示时重新登录。

## 首次配置

租户负责人在页面配置负责确认到账的财务账号。销售、仓库及财务账号应配置相应菜单；仓库账号复用「订单库存核查」权限，并受原有仓库访问权限约束。

新销售订单提交审核前必须选择「款到发货」或「账期」。历史已审核但未填写付款方式的订单，由原销售人员在第一次申请发货时补充一次。

## 操作顺序

1. 销售先与仓库核对，在库存核查中完成整单预留。所有预留批次都必须通过质检并完成领导放行。
2. 原订单销售人员发起发货申请。申请后锁定订单和预留；需要调整时先撤销申请并填写原因，再修改、重新申请。
3. 款到发货订单由配置的财务账号确认足额到账金额和实际到账日期；账期订单无需提前确认收款。尚未出库时财务可以填写原因撤销确认，立即恢复出库拦截。重新申请需要重新确认收款。
4. 仓库逐车填写车牌、司机、联系方式、产品、仓库、批号、装车数量，并上传该车装车照片。可以先保存部分装车安排；每车最终至少一张照片，可上传多张。
5. 全部车辆装好后先保存，再点击统一出库。各产品、仓库和批号的合计必须严格等于预留明细，整单必须齐备。单车不能单独完成出库。
6. 确认后一次生成原系统库存出库单，扣减库存并消耗本单预留。其他订单的预留保持有效。订单页面可查看出库进度，发货页面保留车辆、照片、收款确认及操作记录。

## 数据处理

- 出库时再次核验批次放行、库存、权限、付款条件及装车数量。并发重复点击只会成功一次；记账失败会整体回滚，不会留下扣减了一半的库存或预留。
- 已确认的出库单不能在原单据入口直接修改、反审核或删除；已出库申请不能撤销或撤销收款确认。退货应使用后续业务流程处理。
- 仓库普通账号不展示销售金额和财务确认金额；财务、订单销售人员及租户负责人按权限查看。
- 照片沿用现有本地附件上传目录，上传、预览和服务器备份均依赖该目录。数据库备份应同时保留附件目录。
- 本模块的到账确认是发货条件，不另行生成收款、应收或收入账务。库存出库使用现有库存成本，避免将销售价格直接当作库存成本。发票、回款核销及退货业务不在本模块范围内。
