# 产品用料配置

在“商品管理 → 产品信息”列表点击“用料配置”，或打开产品编辑窗口的“产品用料”页签。新产品需要先保存档案再配置；复制产品不会自动复制用料关系。

一项产品可关联多种有效原料，选择原料后显示其基本单位。参考用量可留空；填写时应大于零，最多六位小数。请在备注写清用量口径，例如“每吨产品的参考用量”或“模拟关联，用量待确认”。同一种原料不能重复选择。

用料配置独立保存，不会自动生成领料单，不会自动算料或扣减库存。领料、仓库发料及生产执行仍按原流程办理。它不是已核定的生产配方。

查看需要产品信息菜单，保存需要该菜单的编辑按钮权限；租户负责人可维护。服务器校验租户范围、产品/原料类型、基本单位、重复关联及修改版本。原料被有效产品引用时，须先解除关联才能删除。

部署前备份数据库，在020迁移之后执行 `021_product_materials.sql`，再更新后端和前端。刷新页面加载新入口。
