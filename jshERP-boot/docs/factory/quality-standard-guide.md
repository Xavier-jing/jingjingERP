# 产品质检标准

入口：商品管理 → 产品质检标准。半成品送检与成品质检仍在生产管理中办理。

## 配置方法

1. 在“共用检测模板”中新建模板，填写模板名称，增加检测分表和指标。
2. 数值指标可填写下限、上限或两者，边界包含在合格范围中；两侧留空则人工判定。
3. 文字指标可填写合格文字，检测结果去除首尾空格后按完整文字比较；标准留空则人工判定。
4. 在“产品标准配置”选择具体产品／型号、半成品或成品。半成品还须选择对应工序；成品标准不随最终工序编号变化。
5. 选择共用模板并保存，或复制模板内容为产品独立标准后调整保存。新增加的有效吨制产品会出现在产品选择框中。

共用模板更新后，所有引用配置的新送检单使用新模板。页面显示引用数量；保存包含版本检查，避免覆盖他人已保存的修改。复制模板会生成独立模板，后续不跟随源模板变化。配置和模板修改记录写入原质检审计记录。

## 权限与检测

质检主任或租户负责人可维护，其他有质检业务权限的人员只读。仅新增菜单权限不会授予维护标准的权限。

检测填报沿用原送检流程。数值超范围、文字与合格文字不一致时标红；仍须保存真实原始结果，不能改成区间值。提交后由质检主任确认，任一有标准的指标不合格时，本次送检合格数量必须为0，并填写处理说明；不得以说明代替不合格判定。成品仍按整批合格或整批不合格判定。

标准在送检时复制到送检单；之后修改产品配置或模板均不会改动原送检单。复检作为新送检单使用当前标准，原不合格记录保留。

## 部署

在原有工厂迁移之后执行 `019_quality_templates.sql` 一次，执行前备份数据库。新增共用模板表，将产品标准按检测阶段区分，并新增菜单。

旧标准继续作为原工序半成品标准；每个产品原有最高工序标准复制为初始成品标准，部署后可在新入口核对调整。既有送检单及其结果完全保留。本机备份在忽略目录 `.quality-local/before-quality-templates.sql`。

新增菜单向原有半成品质检菜单角色开放入口，同时补充商品管理父菜单；具体维护权限仍由后台核查。重新登录加载新菜单。
