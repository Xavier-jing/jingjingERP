# 生产统筹与三个车间主任使用说明

## 当前流程

销售填写生产联系表（含任务时间） → 领导审核 → 生产统筹按产品分配车间、工序和数量 → 各车间主任分别接单 → 各自安排人员、班次 → 各自开领料、补料及退料单 → 仓库确认。

一张销售订单仍对应一张生产联系表；联系表下面分别显示实际参与车间的处理进度。产品不必经过全部三个车间，具体路线由生产统筹决定。

## 先配置人员

1. 负责人账号进入「生产管理 → 生产任务联系表」。
2. 点击上方「生产人员配置」。
3. 设置领导审核人、生产统筹、一车间主任、二车间主任、三车间主任。
4. 三个车间主任须分别使用不同账号。人员账号不足时，先在用户管理创建账号，并为主任分配生产管理菜单及需要使用的仓库权限。

本机保留了原审核账号；原单主任账号转为生产统筹。三个主任没有被擅自指定，需要选择工厂实际人员。变更主任配置后，新主任接管该车间已有任务，之前的接单人及操作记录仍保留。存在待领导审核的联系表时需先完成审核，再修改人员配置。

## 销售与领导

销售订单审核、仓库核查后，销售仍从订单上开生产联系表。填写任务时间、生产要求和生产数量；生产量与仓库缺口不同须填原因。领导审核后，状态为「待生产统筹分配」。

销售和领导可以查看整张联系表、各车间接单与排班进度。销售订单详情也显示车间状态。已有有效生产任务时仍不能直接撤回、反审核或删除销售订单。

### 审批领导反审核

生产人员配置中的领导审核人可选中“待生产统筹分配”的已审核联系表，点击“反审核”并填写原因，联系表退回草稿，由原创建人修改后重新提交。反审核保留原单据、生产要求和数量，增加版本号，并在生产及销售操作记录中保留操作人和原因。

仅限从未下发车间的任务。已有路线、排班、车间任务、领补退料、开工、日报、质检交接或成品记录，以及已有下发历史的任务，后端均阻止反审核。生产统筹、销售及车间主任不能代替领导操作；旧版本请求也会被拒绝。

## 生产统筹分配

1. 统筹账号选中联系表，点击「统筹分配车间」。
2. 按产品行填写工序序号、车间、分配数量。
3. 工序从1连续填写；同工序可分给不同车间，各工序分配总量必须等于该产品生产量。
4. 点击「下发车间任务」。被分配的车间分别进入「待主任接单」。

例如产品A生产10吨：工序1分给一车间6吨、二车间4吨，工序2交三车间10吨。表示先分工、再流转，不是新增生产20吨。

统筹安排产品路线和数量；负责人、人员、班次、具体计划日期由各车间主任填写。某车间接单或排班后，统筹不能直接改掉该车间的路线和数量。尚未接单且没有有效领退料记录的分配可以调整。

## 各车间主任操作

1. 主任使用自己的账号登录，任务列表显示分配到本人车间的任务；若还承担统筹、审核等角色，则可按相应职责查看整体。
2. 选中联系表，点击「本车间主任接单」。详情内也有本车间接单入口。
3. 点击「本车间排班」，从分给本车间的产品工序中添加人员班次安排。
4. 可将同一工序数量拆分到多组人员或班次，合计须等于统筹分给本车间的数量。
5. 填写负责人、人员、班次和计划开工、完成日期，保存。

主任不能替其他车间接单、修改其他车间人员，也不能改变统筹分给自己的工序或总数量。保存本车间排班会保留其他车间已有的安排。

每个车间独立显示「待主任接单 / 主任已接单 / 已排班」。所有实际参与的车间都完成排班后，整张联系表显示「各车间已排班」；尚有车间未完成时显示「各车间处理中」。这些状态不表示已经实际开工或生产完成。

## 各自领料、补料和退料

本车间接单并完成排班后，即可进入「领料 / 补料 / 退料」，不需要等待其他车间全部排班完成。

主任只能开立、修改、提交和撤回自己车间的单据，不能把其他车间单据改成自己的。原料数量仍由主任手填，沿用原料基本单位和批号；仓库确认权限保持独立。

仓库确认发料后才扣库存，收到退料后才增加库存。超发、超退、重复确认及从原系统直接修改库存流水仍受保护。主任的领退料列表按所属车间显示；仓库可统一处理各车间单据。

## 库存变化

仓库调整预留后，联系表继续提示缺口变化。统筹分配、主任接单或排班时，需要与销售协调并确认说明，已经下达的生产数量不会自动改变。

## 旧任务如何处理

升级保留旧联系表、产品数量、任务时间、已填写的车间和人员排班，以及所有库存和领退料记录。

旧「已排班」任务转为各参与车间「待主任确认」。配置好新主任后，各主任接单、核对保留下来的排班并保存，即可继续执行。不会把原来一位主任的操作伪装成三位主任都已确认。

旧任务仅接单但未排班的，转为「待生产统筹分配」。升级前数据库已备份，并保存了原任务数据用于核对。
