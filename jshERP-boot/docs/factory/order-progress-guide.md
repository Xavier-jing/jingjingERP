# 订单全过程进度看板

入口：业务看板 → 订单全过程进度；销售订单选中一单后也可点击“全过程进度”。

## 查看范围

- 销售查看本人订单。
- 车间主任查看分配给本车间的订单，并只显示本车间对应的产品、工序和报工数据。
- 生产统筹、固定审核人及已配置的相关审批领导可查看全部订单。
- 金额沿用销售和财务权限；获得领导或看板权限本身不会额外获得金额权限。
- 进入业务模块仍需具有该模块的菜单和业务权限。

## 内容与数量口径

看板汇总订单审核、库存预留、生产安排、领补退料、实际报工、半成品质检与交接、成品质检与整批入库放行、收款发货、变更取消和客户退货。

产品、工序、车间分别显示投入、产出和损耗。最终产出只计算该产品最后一道工序，不累加不同工序的产出。质检代表数量和复检记录不作为新增生产产量。入库、放行显示历史整批数量，不代表当前可用库存。

“当前待处理事项”按已有业务记录生成。没有记录不表示业务已经完成；可进入对应模块核对。点击“刷新最新进度”重新查询，不保存另一份进度数据。

## 点击办理

环节卡片进入对应订单或任务；检测记录进入对应送检单，变更和退货记录进入对应申请。没有对应模块权限或尚不适用的卡片不可点击。看板只查询，所有修改、审核、收货和出库均在原业务模块办理。

## 部署与验证

执行 `017_order_progress.sql`，新增看板菜单，并向已有销售订单或生产任务菜单的角色添加入口；保留原模块授权边界。执行前备份角色菜单配置。

随后执行 `018_progress_navigation.sql`，将看板移至独立的“业务看板”一级菜单。只给原有看板角色补充父菜单，不改变业务权限及登录首页。重新登录加载新菜单。
